# Pathfinder Track MVP

Static PWA MVP for Pathfinder club management. The app uses Supabase Auth REST + PostgREST directly with a publishable key, so no frontend framework or package install is required for the first deployment.

## MVP screens
- Invitation-only sign-in
- Mobile-first counselor dashboard
- Unit roster
- Meeting attendance and 45-point merit scoring
- Demo preview mode

## Next implementation steps
- Write meeting attendance and scores back to Supabase
- Director dashboard and member management
- Class requirements progress UI
- Parent/Pathfinder read-only portal
